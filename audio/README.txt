音乐文件（只在本机）
====================

这个文件夹里的 mp3 不会发布：
.gitignore 忽略了 audio/*.mp3 等音频格式，所以它们不会进仓库，
也不会出现在线上站点（https://xuzihan115.github.io/personal-homepage/）。

为什么这样安排
--------------
站点原先有「首页音乐卡」和「歌库」页，后来整体删掉了，音频也一并
从发布内容里拿掉——把商业歌曲的完整音频传到公开网站上属于侵权风险。

想再听这些歌
------------
直接用本机播放器（或资源管理器双击）打开 audio/ 里的文件就行。

如果想重新做回歌库功能
----------------------
1) 从 git 历史里找回歌库相关文件：

       git checkout 3ccbc10 -- js/library.js audio/library.js

2) 跑扫描脚本，按「歌手 - 歌名.mp3」的文件名生成清单：

       node tools/scan-audio.js

   （只想看看识别结果、不写文件：加 --dry）

3) 在 index.html 里重新加回 audio/library.js 与 js/library.js 的
   <script> 标签，以及首页卡片 / 独立页面结构，再恢复对应的 CSS。

几点注意
--------
- 版权：只放自己有权利公开分享的音频；课程作业建议用无版权音乐
  或自己录的素材。
- 体积：音频很占空间。GitHub Pages 建议仓库控制在 1GB 以内、
  月流量 100GB 以内，所以别把 audio/ 整体提交上去。
- 格式：mp3 最稳。浏览器解不了 wma，扫描脚本会提醒你转格式。
- 页面不会自动播放（浏览器策略会拦），要手动点一下播放键。
