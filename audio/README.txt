音乐放这里
==========

把音频文件放进这个 audio/ 文件夹，刷新页面就会自动认出来。
支持 mp3 / wav / m4a / ogg / flac / aac / opus（能不能放，取决于浏览器解不解得了）。

两种放歌的方式
--------------
1) 放进 audio/ 目录：页面会按下面的顺序挨个试，认到第一个就停。
   自动识别的文件名（按顺序）：
     song.mp3   music.mp3   1.mp3   track.mp3   bgm.mp3   歌.mp3   春风吹.mp3
   想听什么歌，把文件名改成上面任意一个即可（一般用 song.mp3 最省事）。
   注意：一次只会认到其中一首；想多首请用下面第 2 种方式。

2) 拖进卡片：打开主页，把音频文件直接拖到「正在播放」那张卡片上；
   也可以点卡片里那一行右侧的选择文件按钮，一次挑多个。
   这种方式不用管文件名，可以一次放好几首，能上一首 / 下一首切换。

其他说明
--------
- 浏览器不允许网页自己扫描本地文件夹，所以「自动识别」只能按上面那些固定
  文件名去猜，这是浏览器的限制，不是主页偷懒。
- 页面不会自动播放（浏览器的自动播放策略会拦），需要手动点一下播放键。
- 支持单曲循环、上一首 / 下一首、音量、点进度条跳转。
- 歌文件体积大，不建议提交到 Git。只把这张说明留在版本库里，保证 audio/
  目录不会在别人克隆时消失。
