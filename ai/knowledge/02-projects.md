## 个人主页项目（代表作品）

- 线上地址：https://xuzihan115.github.io/personal-homepage/
- 源码：https://github.com/XUZihan115/personal-homepage
- 方式：Vibe Coding，纯 HTML / CSS / JavaScript，不用框架、无构建步骤、离线可用。
- 过程：五周做了四个版本（v1 9/3 → v2 9/17 → v3 9/18–9/22 → v4 10/7），每一版都打 tag、留归档，可以单独回退。
- 有一整版（太阳系动画背景）做出来后被他本人评审否决：先留档，再从上一个提交重做。原因：整页动画和「读内容」这个目标天然冲突。
- 验证：240 项自动断言 + 52 项线上核对；『看着没问题』从来不是验收标准。
- 踩过的坑：七段数码管时钟少了一位数字（AI 自己写的冒烟测试逮到的）；汉字笔顺坐标上下颠倒（坐标系原点不同）；留言板数据库因为闲置被免费套餐删除（已换新库并加每三天探活的 GitHub Action 保活）；手机版因为 touch-action 规则导致页面滚不动（真的用手机打开才发现的）。

## 主页的主要功能模块

- 可拖拽卡片式主页：六张卡片自由拖动，位置存在浏览器里，「归位」一键还原；窄屏自动变单列。
- 「数字分身」独立页面：顶部导航「数字分身」进入（在「联系」和「换设备」之间），DeepSeek 大模型驱动的聊天问答，分身基于主页全部公开资料回答访客问题。
- 汉字笔顺动画：名字按真实笔顺逐笔书写（徐 10 画、子 3 画、涵 11 画），写完停顿再清空重写。
- 七段数码管时钟：CSS 画的数码管，每秒刷新，配日期和按时段变的问候语。
- 太阳与月亮：Three.js 自定义着色器——太阳是程序化日面（米粒组织、黑子、临边昏暗、日珥弧环）；月亮用 NASA LRO 反照率贴图派生高度做出月海起伏。点击切换。
- 画作画廊（「联想一下」）：公有领域画作全屏展示（莫奈《日出·印象》等），单击换画、双击退出。
- 日间/夜间主题：蓝绿浅色日间主题 + 深色夜间主题，改动全部限定在 body.bg-sun 作用域内。
- 留言板：Supabase 数据库，匿名访客可读可写、不可改不可删；诚实报错，不静默吞留言。
- 设备选择页：根地址选手机/电脑，记住选择；手机版是专门做的单列版面，不是把桌面网格压扁。
- 无障碍：支持系统「减少动态效果」，名字书写、终端打字、日月自转都会停。
- 性能（v4）：首屏少下载约 767 KB；画作改为按需加载、预取分级；补了 favicon 和完整的 og:/twitter: 分享卡片。

## Python 小工具（迷你项目页，全部能在线试）

- BMI 计算：输入身高体重算 BMI，身高体重明显不合常理时会提示单位写错了，不会硬算。
- 摄氏 / 华氏转换：结果保留一位小数，输入不是数字会提示重试。
- 进制转换：2–10 进制互转，先校验数字合法性再算。
- 斐波那契第 x 项：用循环不用递归，项数大也不会卡死。
