# 数字分身 · 训练与接入说明

> 这是期末版本的「训练」工作区。训练 ≠ 微调模型，而是 **资料整理 + 提示词工程 + 测试调优** 三件事，做完接入真实 API 就能用。

## 目录结构

```
ai/

├── system-prompt.md       ← 说话规则（分身的"性格"）

    ├── 02-projects.md     ← 项目、技术、踩过的坑
    ├── 03-interests-views.md ← 兴趣与观点（用原话，不发明新观点）
    └── 04-boundaries.md   ← 边界红线 + 标准婉拒话术
```

## 训练五步（照着走一遍，期末报告也有素材了）

1. **整理资料** → 已完成（从主页 + 期中报告提取）。你要做的是过一遍，把不准确的地方改掉，把自己想加的新资料（比如为什么选这个专业）补进去。
2. **写说话规则** → 已完成（system-prompt.md）。过一遍语气像不像你，不像就改。
3. **接入真实模型** → 见下面「模型与部署」。这是唯一需要你出钱/出账号的环节。
4. **跑测试集** → 用 test-set.md 的 30 题逐题测，记录问答，算命中率。这是期末报告里「效果如何」的证据。
5. **调优** → 哪类题不过线，就改对应文件：事实错 → 改 knowledge/；语气不像 → 改 system-prompt.md；边界失守 → 改 04-boundaries.md。改完重测。

## 模型与部署（选一个方案）

| 方案 | 费用 | 访客在国内能否访问 | 说明 |
|------|------|-------------------|------|
| A. 前端直连（key 写进页面代码） | 一个 API key 的充值费 | 取决于模型厂商（DeepSeek/通义/Kimi 在国内都通） | 最快，作业够用；**key 会暴露在网页源码里，任何人能看到**，所以用完后要作废/限额 |
| B. 云函数代理（推荐） | API 费 + 云函数免费额度 | 选国内服务商（阿里云函数计算 / 腾讯云函数）就通 | key 藏在云函数里，前端只调云函数；多一道部署，但安全、访客在国内也能用 |
| C. 本机演示 | API 费 | 只有你自己能访问 | 老师要的是「链接能打开」，本机演示没法交作业，只能当调试用 |

**模型建议**（参考学长的经验帖）：
- 有现成 OpenAI key 和余额 → 直接用，不用额外花钱。
- 没有 → 建议 DeepSeek（api.deepseek.com）：中文好、按量计费、充值门槛低（十到二十块对作业规模完全够用）。
- 判断标准：中英文过得去、支持长上下文、按 token 计费。别用旗舰模型，浪费。

**选型关键问题：访客在哪？** 访客在国内 → 千万别用 workers.dev 这类国外免费域名（国内打不开）；用国内服务商，或者直接前端直连国内模型厂商（方案 A 在这个前提下反而最省事）。

## 接入步骤（方案 A，已完成 ✅）

1. 注册 platform.deepseek.com → 充值 → 创建 API key。
2. 聊天 UI 已上线：`js/avatar.js`（对话区 + 输入框 + 发送按钮），已接入 `desktop.html`（第 7 张卡片「数字分身 · 问子涵」）和 `mobile.html`（单列第 7）。
3. 调用方式：前端 fetch 直连 `https://api.deepseek.com/chat/completions`（OpenAI 兼容格式），system 消息 = system-prompt.md + 四份 knowledge/ 全部内容（内联在 avatar.js 的 KNOWLEDGE 常量里，与 ai/ 目录同步，改资料两处都要改）。
4. 关键参数（写报告用）：
   - 模型：`deepseek-flash`（DeepSeek-V4.1-Flash-1017）
   - CORS：已实测预检 OPTIONS + 带 Origin 的 POST，DeepSeek 服务端返回 `access-control-allow-origin`，**浏览器直连可行**（本地 http://127.0.0.1 与线上 github.io 来源均已验证）
   - 上下文：system + 最近 12 条消息（省 token），max_tokens 2048，temperature 0.8
   - 报错处理：402（余额不足）/ 401 / 403 / 429 各有访客可读的友好提示，不暴露技术细节
5. 测试已完成 ✅：2026-11-05 首轮 32/32 命中，四类各 8/8（见 `test-report.md`），达到上线门槛（每类 ≥6/8）。改资料后需重跑。
